PRIMARY RESPONSIILITIES OF OPERATING SYSYTEM

The main purpose of operating system is to act as an intermediatry between computer hardware and use applications or users. It manages system resources such as CPU,RAM, Keyboards, Mouse , etc.

DIFFERENCE BETWEEN PHYSICAL HARDWARE AND SOFTWARE INSTRUCTIONS

Pysical hardware is tangible equipment while sofware is a code written to tell physical hardware what to do.

5 INTERNAL HARDWARE COMPONENTS

a. CPU - A central processing unit, often called brain of the computer. it basically tells all other components what to do.
b. Hard drive - stores information permanantly.
c. RAM - Stores information temporarily
d. Heat Sink - cools the CPU to optimize performance
e. Motherboard - a place where all components placed on.
